\## Descripción



Aplicación móvil para la gestión de usuarios y enfermedades mediante almacenamiento local utilizando TinyDB.



La aplicación permite realizar operaciones de registro, consulta, actualización y eliminación de información.



\## Funcionalidades



\- Registro de usuarios.

\- Inicio y cierre de sesión.

\- Recuperación de contraseña mediante correo electrónico.

\- Gestión de usuarios.

\- CRUD de enfermedades.

\- Consulta de enfermedades por ID.

\- Consulta de enfermedades por nivel de gravedad.

\- Consulta de usuarios por nombre de usuario.

\- Consulta de usuarios por correo electrónico.

\- Persistencia local mediante TinyDB.

\- Uso del sensor de ubicación.

\- Uso del sensor acelerómetro.



\## Archivos



\- `GestionEnfermedades.aia`: código fuente del proyecto Kodular.

\- `GestionEnfermedades.apk`: aplicación compilada para Android.



\## Instalación



1\. Descargar el archivo `GestionEnfermedades.apk`.

2\. Transferirlo a un dispositivo Android.

3\. Autorizar la instalación de aplicaciones desde fuentes externas si Android lo solicita.

4\. Instalar y ejecutar la aplicación.
